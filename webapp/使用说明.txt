SignStudio 零安装版 —— 不需要安装 Python、不需要联网

怎么用
  1. 解压后（务必保留 libs 文件夹）双击「签章工作台.html」
     用 Chrome 或 Edge 打开（Windows 默认就是 Edge）
  2. 点「＋ 打开 PDF」选择日报 PDF
  3. 点「＋ 导入签名 PNG」选择签章图片（可多选）
     左侧选中某个签名，底部可设「默认宽度(mm)」，高度自动等比
  4. 在预览页面上拖一个框 → 盖章（框多宽章就多宽）
     单击页面 → 按默认宽度居中放置
     章可拖动位置、拖右下角小方块改大小、点右上 ✕ 或按 Delete 删除
  5. 点「⤓ 一键导出 PDF」→ 浏览器下载「xxx_已签章.pdf」

精确改尺寸（手动输入毫米）
  · 点一下页面上的章，或点右侧清单里的那一项 → 右下角出现「选中章」面板
  · 直接输入 宽 / 高 / X / Y 的毫米数，边输边生效
  · 默认勾着「按原比例」：改宽→高自动跟随，改高→宽自动跟随，另一边按原图比例算
  · 取消勾选才能自由拉伸（比如把签名压扁塞进窄栏位）
  · 适合先把签字章统一成固定毫米尺寸（比如 30×16mm）再逐页放

工程模板
  · 放好所有章后点「保存为工程」，起个名字
  · 以后打开新日报 PDF → 点「载入工程」→ 选名字 → 章自动铺回原位 → 直接导出
  · 工程保存在本浏览器本地（localStorage），换电脑或清理浏览器数据会丢失。

把工程搬到完整版（带界面的 Python 版）
  · 点工具栏「导出工程」→ 下载 SignStudio零安装版工程.json
  · 打开完整版 → 点「导入工程」→ 选这个 json → 提示「已导入 N 个工程」
  · 之后在完整版里正常「载入工程」即可，坐标和签名图都保留
  · 也可用 F12 → Console → copy(localStorage.getItem('signstudio_projects_v1')) 复制 JSON 备用

怎么更新（一键，不用手动拷文件）
  · 双击本文件夹里的 UPDATE.bat
  · 它会自动：读更新清单 → 下载新版零安装包 → 校验 sha256 → 解压 → 覆盖本文件夹，
    旧版 HTML 会先备份成 .backup_日期时间 文件夹
  · 跑完重新双击「签章工作台.html」（建议 Ctrl+F5 刷一下）即可
  · 页面顶部如果出现黄色「发现新版本」提示，也照上面双击 UPDATE.bat 就行
  · 签名图和工程模板存在浏览器里，更新不会丢
  · 没装 PowerShell（极老系统）时才会失败，那就手动下载压缩包解压覆盖

特性
  · 红章自动正片叠底：章盖在文字上时底层文字仍清晰可见（和真实盖章一致）
  · 图片一律按 PNG 处理，白底自动洗透明
  · 导出 300dpi，坐标精确到 0.1pt

注意
  · 必须用 Chrome / Edge 打开，IE 和旧内核浏览器不支持
  · 如果双击后页面空白，说明 libs 文件夹没解压出来，请重新完整解压
